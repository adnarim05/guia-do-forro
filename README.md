# Guia do Forró

Protótipo navegável de um app de estudos para quem dança forró e evolui por níveis de colar (Transparente, Branca, Azul, Preta e Vermelha).

**Abrir o protótipo:** https://adnarim05.github.io/guia-do-forro/

## O que dá para testar

- Trilha de colares e página de cada nível
- Biblioteca de passos com busca, filtros e detalhe do passo
- Critérios de cada exame e checklist pessoal de estudo (só para estudo, nunca indica aprovação)
- Combinações da roda, fotos e vídeos, agenda de eventos
- Perfis Aluno, Colaborador e Curador (troca em **Perfil**)
- Tema claro e escuro, modo offline simulado, estados de carregando, erro e vazio

## Sobre os dados

- Todo o conteúdo fica na memória do navegador e volta ao início quando a página é recarregada.
- Combinações, mídias e eventos marcados como **Exemplo** são fictícios.
- Itens em que o manual de referência se contradiz aparecem como "Aguardando confirmação do curador".

## Tecnologia

Um único arquivo `index.html`, com HTML, CSS e JavaScript puro e sem build. O layout é responsivo: barra inferior no celular, trilho lateral no tablet e menu lateral com lista e detalhe no computador. Segue o Material Design 3.

Para rodar localmente, abra o `index.html` no navegador.
